# Implementation Roadmap

## 0–30 days
Appoint owners; confirm legal applicability and commencement dates; inventory assets and data; review privileged accounts; confirm incident contacts.

## 31–60 days
Verify privileged MFA; approve access and incident procedures; document log sources and retention; define patch targets; assess critical suppliers.

## 61–90 days
Remediate priority vulnerabilities; run an incident tabletop exercise; test backup restoration; review privacy notice and retention; train staff.

## 3–6 months
Complete independent application security assessment; close high-risk gaps; test disaster recovery; reassess suppliers; report KPIs to governance.

## Suggested KPIs
Privileged MFA coverage, access-review completion, critical patch compliance, log-source coverage, restore-test success, training completion and overdue high-risk actions.
