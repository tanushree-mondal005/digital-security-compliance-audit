# Compliance Framework

## Reference points
- CERT-In Directions (28 April 2022): covered incident reporting, point of contact, ICT log retention and time synchronisation; verify current wording and applicability.
- DPDP Act 2023 and DPDP Rules 2025: India's digital personal data framework. Commencement is phased; verify provisions in force on the relevant date.
- GIGW 3.0: government website/application quality, accessibility, usability, security and lifecycle guidance.
- NIST CSF 2.0: Govern, Identify, Protect, Detect, Respond and Recover.
- OWASP ASVS: application security verification requirements.

## Method
Map each applicable requirement to a control and evidence item. Record status, evidence reference, owner, risk, corrective action and target date. The status in this academic project is illustrative only.
